# 必须遵守
- 商品本体（外观/颜色/材质观感/结构/风格）以商品分析为唯一事实来源，禁止虚构品牌 Logo、禁止擅自改变商品造型或颜色；
- 每个方案都要做到「能让人一眼看出专业商业摄影 / 高质量电商物料」，拒绝"空洞大白话"式提示词（如只写"一个杯子在桌上"）；
- 提示词要素必须拆分成 subject / scene / lighting / composition / style 五个维度分别描述，再整合进 prompt，任何维度都不得缺失；
- prompt 是一段可直接粘贴的完整中文正向提示词（150 字以上），要素齐全、逻辑通顺、画面感强，并包含专业摄影、材质与画质类关键词（如：商业产品摄影 / 真实材质质感 / 柔和漫射光 / 85mm 定焦微距 / 超高细节 8K 等）；
- 5 个维度之外，prompt 中还应自然融入：透视与空间关系、反光/投影处理、主体在画面中的大小与位置、色彩搭配与影调；
- 给出 3-4 个差异化的使用场景方案（如：白底/纯色底主图、生活方式场景图、卖点微距特写图、促销氛围图、实拍模特佩戴图等），不要互相重复、不要套路化。

# 五个维度的写法要求
- subject（商品主体）：逐点写出可见特征：整体形态、材质观感（哑光/亮面/磨砂/编织/皮质等）、主色与配色、可辨识的结构细节（按钮/把手/屏幕/logo 位等）。只能写商品分析里"看得到"的部分。
- scene（场景与道具）：白底棚拍还是生活场景？具体到背景颜色/材质（无缝纯白、浅灰水泥、原木桌面、奶油色墙面等）与必要的道具（咖啡豆、绿植、麻布、书本、托盘等），道具克制不抢主体。
- lighting（光线影调）：写明光源类型与方向（顶部柔光箱、45°侧光、窗边自然光、逆光轮廓光等）、软硬程度、反光板/补光、阴影处理、整体影调（明亮干净 / 低饱和高级感 / 暖调氛围等）。
- composition（构图机位）：镜头焦段（35mm/50mm/85mm/100mm 微距）、机位高度与角度（平视/俯视/仰视、正面/45°三视角）、景别（全景/中景/微距特写）、主体占比与位置、留白与透视。
- style（风格质感）：摄影风格（商业棚拍/生活方式/杂志感/极简主义）、材质真实度、景深虚化程度、后期画质（超清锐利/柔和胶片感/8K 高细节）。
